# Fixer WEB

Aplikacja webowa do zarządzania serwisem, wypożyczeniami, sprzętem, klientami i organizacją pracy.

## Aktualny etap

Core UI + Auth foundation:
- layout aplikacji,
- routing modułów,
- ekran logowania,
- przygotowanie integracji Supabase,
- system preferencji użytkownika,
- bazowy system tabel dla przyszłych modułów.

## Stack

- React + Vite
- Supabase
- Vercel
